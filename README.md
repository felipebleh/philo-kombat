# Philo Kombat — Uma batalha de ideias

Jogo de luta filosófico criado por Felipe Camargo. Em **Philo Kombat**, pensadores, poetas e sábios de diferentes épocas se enfrentam por meio de golpes, habilidades especiais e diálogos inspirados em suas ideias.

## Versão atual

Personagens jogáveis:

- Platão
- Nietzsche
- Amenemope
- Homero

Cada personagem possui arena, identidade visual, animações, golpes e interações próprias.

## Controles

| Ação | Tecla |
|---|---|
| Movimentação | Setas direcionais |
| Soco | J |
| Chute | K |
| Especial 1 | L |
| Especial 2 | U |
| Combo | I |

O jogo também possui suporte a mouse e toque nas telas de seleção.

## Destaques

- escolha livre do lutador e do adversário;
- confrontos sem personagens duplicados;
- diálogos exclusivos antes e depois das lutas;
- arenas inspiradas na Grécia Antiga, Egito, Sils Maria e Troia;
- golpes especiais ligados às obras e aos conceitos de cada personagem;
- interface adaptada para computador e dispositivos móveis.

## Executar localmente

Requisitos:

- Node.js 22.13 ou superior;
- npm.

```bash
npm install
npm run dev
```

Depois, abra o endereço indicado no terminal.

Para gerar a versão de produção:

```bash
npm run build
```

## Projeto educacional

Philo Kombat foi concebido como uma experiência de aprendizagem em que a História da Filosofia deixa de ser apenas conteúdo expositivo e se transforma em encontro, conflito e criação. Os diálogos e habilidades procuram traduzir conceitos filosóficos em linguagem de jogo sem substituir o estudo das obras.
